# Yellow Zone Real Website System

مشروع من موقعين منفصلين:
- `yellow-zone-client/` الموقع الرئيسي للزوار.
- `yellow-zone-admin/` لوحة الإدارة.

الصفحات الرئيسية في موقع الزوار:
- `index.html` الأسعار الرئيسية + الحجز + المعرض.
- `trips.html` الرحلات المدرسية.
- `birthdays.html` أعياد الميلاد والحفلات.

الأسعار المأخوذة من الصور الرسمية:
- وقت مفتوح: 75 ريال.
- ساعتان: 60 ريال.
- ساعة: 45 ريال.
- تجديد ساعة أو جزء منها: 20 ريال.
- رحلة مدرسية: 60 ريال وتشمل وجبة مجانية.
- عيد ميلاد 10 أطفال: 1350 ريال.
- عيد ميلاد 15 طفلًا: 1800 ريال.
- طفل إضافي: 90 ريال.
- فقرة الساحر: 300 ريال.
- رسم على الوجه: 10 ريال.

الربط يستخدم Supabase للمشروع الحقيقي. لا يوجد دفع إلكتروني في هذه المرحلة، والحجز فقط.
